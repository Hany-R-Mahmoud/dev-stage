# Expanded Social Media Posts for Published Projects

Thirty expanded, copy-ready captions for LinkedIn, Facebook, and X/Twitter: one English and one Arabic version for each published project. These versions add feature summaries, technology stacks, focused hashtags, and direct calls to action.

These captions are best suited to LinkedIn, Facebook, and X accounts that support long posts. The shorter versions remain available in `docs/social-media-project-posts.md` for standard short-form publishing.
